## Summary

Fix the Railway healthcheck failure introduced by the workspace extraction. The app-local start
command was running from `apps/walking-pace` without a local TypeScript config, so Bun compiled TSX
with the default React JSX runtime and exited before binding `/healthz`.

## Goals

- Restore the root `bun run start` path used by Railway.
- Add an app-local `tsconfig.json` so package-local app scripts compile Hono JSX correctly.
- Add a production-start healthcheck smoke test to catch this failure before deploy.
- Include the smoke test in `bun run verify`.

## Non-Goals

- No runtime feature changes.
- No Railway project setting changes.
- No database migration changes.

## Architecture Notes

The deploy command remains `bun run start` from the repository root. The root script now uses Bun's
`--cwd` flag to run the app entrypoint from `apps/walking-pace`, and the app workspace owns a small
`tsconfig.json` that extends the root config so Bun sees `jsxImportSource: "hono/jsx"` when scripts
execute inside the app package.

## Integration Plan
