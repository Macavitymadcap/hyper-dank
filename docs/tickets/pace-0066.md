## Summary

Give the public docs and Storybook surfaces a coherent public story. This pass should make
Hyper-Dank's value, constraints, package status, docs structure, and Storybook reference clear in
British English, then attach enough evidence for the umbrella PR to be reviewable.

## Goals

- Run a copy pass across root README, package READMEs, docs-site pages, Storybook guide copy, and
  any public screenshot descriptions changed by the epic.
- Make the advantages concrete: server-rendered JSX, HTMX-native interactions, Hono routes,
  reusable package boundaries, Bun automation, compatibility tests, and static docs/storybook
  publishing.
- Make the constraints concrete: opinionated hypermedia-first shape, no SPA framework, app-owned
  auth/domain schema/content, and any package distribution limits discovered by the audit.
- Capture light/dark evidence for changed public docs and Storybook surfaces where useful.
- Leave GitHub Issues/Projects workflow and final source-of-truth rules to `pace-0067`.

## Non-Goals

- No new docs architecture, API reference, Storybook feature work, or GitHub workflow changes beyond
  final consistency fixes.
- No package publication or release automation.
- No starter generator or template repository.
- No hidden expansion of source package APIs.
