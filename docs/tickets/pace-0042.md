## Summary

Review the current documentation set for accuracy, relevance, gaps, duplicated claims, and weak
copy before the larger docs rebuild starts.

## Goals

- Audit `README.md`, `ARCHITECTURE.md`, `CONTRIBUTING.md`, `site/`, package READMEs,
  `docs/deployment/`, Storybook guide stories, tickets, and epics.
- Identify stale references, especially Jekyll-specific build claims that later tickets will
  replace.
- Improve copy where it can be safely tightened without changing architecture.
- Produce a source-of-truth map that says which document owns each major topic.

## Non-Goals

- No public site layout changes.
