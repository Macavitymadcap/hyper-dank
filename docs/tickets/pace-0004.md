## Summary

Document and enforce the epic-and-ticket branch flow so epic branches target `main`, ticket branches target their parent epic branch, and planning docs are present before implementation starts.

## Goals

- Update contribution, README, branch protection, and pull request template docs.
- Add an epic template and update the ticket template with parent epic metadata.
- Add a GitHub Actions branch-flow check for epic and ticket PR relationships.
- Require the new branch-flow check in main branch protection config.

## Non-Goals

- No branch creation helper scripts.
- No changes to Conventional Commit title validation.
- No changes to release-please release token handling.
